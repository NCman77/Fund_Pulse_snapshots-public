# Public data policy

Allowed: explicitly approved public fund identifiers and names; official NAV disclosures; public manager, holdings, share-count, weight, industry, and holding-class disclosures; public holding-to-ticker mappings; approved public indices, FX, futures, and ticker quotes; market status and calendar data; source URLs; disclosure dates; capture timestamps; and non-model OHLC/quote fields.

An approved public configuration is not a private watchlist. It is a reviewed list of public instruments that this repository is allowed to collect. The repository must never read a private repository to build or update that list.

Forbidden: personal user data, private watchlists, model or valuation outputs, feature values, recommendation outputs, training data or labels, calibration data, confidence or quality scores derived for a private model, credentials, private responses, IP addresses, and error stacks.
